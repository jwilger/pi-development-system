(for example "first-session success from 22% to 25%"). An output ("ship X") is not an outcome.

## Customers and the problem

is evidence and what is belief.

## Four risks

| Risk | What could be wrong | Evidence so far | Cheapest test |
|---|---|---|---|
| Value | Nobody wants or uses it | unassessed | |
| Usability | People cannot work it out | unassessed | |
| Feasibility | We cannot build it | unassessed | |
| Viability | It does not work for the business | unassessed | |

"Unassessed" is a legal state. Writing it is better than guessing.
