## architecture-review-integration — Integrate authenticated semantic evidence into existing review

**Goal:** Extend existing review rounds, not a parallel service, with mandatory architecture semantic evidence usable by the coordinator's commit/delivery guards. Preserve ordinary legacy review without giving it architecture credit. Work within the already-approved unmerged architectural decision and root architecture goals.

**Files:** Own only `src/core/review.ts`, `src/review/digest.ts`, `src/review/review-tools.ts`, `src/review/submit-tool.ts`, `src/review/submissions.ts`, new `src/review/architecture-evidence.ts`, and review-specific tests under `test/review/` or `test/core/` (not `architecture-review.test.ts`). Coordinator owns runtime, guards, history adapter, documentation and all other files. No dependencies, ADR edits, commits, push or delegation.

**Interfaces:**

- `src/state/architecture-history.ts` inspection now returns `.binding: ArchitectureBinding` produced by `bindArchitectureReview`, including adoption, authority, HEAD, staged tree and complete ordered source/result units. Request is `{kind:"commit"}` or `{kind:"delivery",resulting?:readonly string[]}`. Structural violations and typed errors must refuse semantic preparation, not be treated as approval.
- Pure core `src/core/architecture-review.ts` exposes `ArchitectureBinding`, `ArchitectureReceipt`, `ReviewerOrigin`, `acceptArchitectureReceipt(binding,evidence:unknown,hostOrigin,expectedReviewer)` and `checkArchitectureReview(binding,receipts:readonly unknown[],expectedReviewers:readonly ReviewerOrigin[],requiredCleanDepth:number)`. Read exact owned core contracts; do not change that file. Check coverage, explained six-check evidence, findings and exact bindings through those functions.
- Runtime host API `src/subagents/orch/tool-caller.ts`: `expectInheritedReviewer(rootId,threadPath)` returns immutable `{rootId,threadPath,attemptId}` and registers a single-use dispatch; `forgetInheritedReviewer(rootId,threadPath)` cancels it; `inheritedToolCaller()` returns host-owned `{rootId,threadPath,parentPath,agentType,sessionFile,attemptId}` or undefined. Fresh independent runtime with type `reviewer` claims issued attempt; restored runtimes cannot claim it and get a fresh attempt. Never accept origin from model arguments. Root origin must match `ctx.sessionManager.getSessionId()`; path must be an exact fresh independently rooted `/review-...` dispatch, `parentPath === null`, `agentType === "reviewer"`, nonempty owned sessionFile and exact issued attempt. SessionFile is pinned from that host caller, never supplied by model. Wrong attempt, root, unrelated child and coordinator-pasted markdown give no architecture credit.
- Generate dispatch paths with random UUID component within the 64-character segment limit; timestamp alone is insufficient. Persist issued expected dispatch alongside pending binding BEFORE returning spawn payload. For failed/reloaded attempts provide explicit `restart` on review start: mint a fresh path/attempt without discarding accepted rounds or lowering clean depth. Reissue no consumed attempt for a restored child.
- Review start supports architecture boundary `commit | delivery` and optional explicit resulting revisions; default commit. When explicit architecture config exists, prepare semantic evidence automatically for every review; absent adoption may still permit ordinary legacy review but supplies NO semantic credit (coordinator's commit guard refuses unresolved adoption). Explicit architecture requests without adoption fail closed. An empty working diff must not suppress review of pending/resulting units.
- Include exact binding and ordered immutable unit inspection instructions/schema in reviewer task appended to existing policy; add model evidence parameter to submit tool, no origin parameter. Include architecture identity in review input hash when present, preserving legacy hashes when absent. Reinspect after awaited judgments and before recording; compare all bindings, not only diff digest. Exact bindings apply to the complete sequence, never per-file subset credit.
- Keep full evidence, sources, binding, expected dispatch and host origin through submission combination and accepted round persistence. Persisted legacy rounds remain readable but have no architecture credit. Boundary-parse new optional state, refusing malformed data instead of dropping it. Ordinary markdown fallback remains ordinary; no model-authored identity or pasted prose can manufacture a host receipt. Preserve blocking ordinary findings even when semantic approval is refused; never turn a negative semantic result into a clean round.
- Export from new `src/review/architecture-evidence.ts` a small guard-facing function `architectureReviewGap(review: ReviewState | undefined, binding: ArchitectureBinding): string | undefined` that checks configured required clean depth using full accepted receipt/expected-origin pairs. Also export any needed round/pending metadata types there or core/review, avoiding runtime import cycles. Gap wording must clearly distinguish missing/stale semantic evidence from structural failure. This function does not itself inspect Git or prove semantic truth.

**First failing test:** A structurally valid binding reviewed by root/coordinator with plausible semantic evidence cannot receive architecture credit. Use real pi SDK tool execution/inherited child bridge for at least one positive and one negative submission test; helpers alone are insufficient. Scaffold missing exports if necessary, then observe actual assertion RED before behavior code.
